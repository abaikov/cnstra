# @cnstra/sync

`@cnstra/core` is a peer dependency: the receptors' collaterals must come from the same copy of core as the rest of your graph.

The homeostat core: keep local data equal to its source, with any state manager. Bindings: [`@cnstra/oimdb`](../oimdb) (OIMDB), [`@cnstra/mobx`](../mobx) (MobX).

A query runs its request in the state manager's reactive layer; CNStra hears what happened. The deciding code lives here and is the same for every binding.

| export | what it is |
|---|---|
| `CNSHomeostatReceptor<TKey, TData>` | a query's definition: `name`, `transduce(key, abortSignal)?`, `staleTimeMs?`, `homeostatRefractoryPolicy?`, `stimulationOptions?`; `axon` — `homeostatFired`, `homeostasisRestored`, `homeostasisFailed`, `homeostasisCancelled`, `homeostasisDisturbed` (the record goes `Stale`: its `staleTimeMs` passed, `invalidate`, or an answer is cancelled because an `invalidate` came after its request started), each with `key` and `firingNumber`; `neuron` has no dendrites; `CNSHomeostatReceptorCorrection` is the only writer of records |
| `CNSHomeostatReceptorCorrection` | `{ homeostatReceptors, reduceHomeostatCorrectionState? }` — the neuron that writes an answer as `Restored` or `Failed` (`reduceCNSHomeostatCorrectionState` by default); finds the repository in the stimulation context, so an answer without it (a resumed run) writes nothing; an answer older than the record is dropped |
| `CNSHomeostatRegulator<TKey, TData>` | per receptor and environment: `createHomeostasisQuery(key?, keyHash?, isObserved = true)`, `observe(query)` / `unobserve(query)` — a query that is not observed works out `Firing` but starts its request only when it is observed (the OIMDB binding observes on the slot's first subscriber), `createHomeostatSource(key)`, `homeostatSourceKeyHashOf(query, source)` — the key hash, computed once per key object and kept on the query, `regulate(query, source, record)`, `regulateSourceTracking(query, source \| undefined, record)` — `undefined` is `Idle` with `key: undefined` — fire after the derivation, pause, idle, join the running request of the key, settle; `release(query)` — leave the request (aborted when its last holder leaves); when the last query holding its key leaves, the repository is told (`unholdHomeostatCorrectionState`) and decides how long the record stays; a query settles on a `Restored` record before its refetch time without a request (never stale without a `staleTimeMs`); a new source of the same key keeps the running request, and asks a `Failed` key again; `invalidate(key)` — also while the request runs; returns a promise of the value the key settles on after the refresh, `undefined` when no query holds the key; an answer to a request that started before the last invalidate is not delivered (`homeostasisCancelled`, the record stays `Stale`, the queries ask again); `invalidateByKeyPrefix(keyPrefix)` — `invalidate` of every held key whose leading parts have the `keyHashFn` of the prefix, a promise of their values (`[]` when none matches; kept records nobody holds are not touched); a writer that fails on a `Restored` answer makes the regulator stimulate `homeostasisFailed` for that request, so the record goes `Failed`; `dispose()` — aborts every running request and releases every held key as its last query leaving would (scheduled refetch cancelled, pending `invalidate` promises resolved with `undefined`, `unholdHomeostatCorrectionState`); after it `regulate` returns the last value or `Idle` and fires nothing, `invalidate` resolves with `undefined`, `invalidateByKeyPrefix` with `[]`, and neither writes |
| `CNSHomeostatEnvironment` / `createCNSHomeostatEnvironmentOptions` | base of a binding: `homeostatEnvironmentOptions` — every part, filled (wrap a default from here to replace it), `homeostatCorrectionRepositoryOf(receptor)` and `homeostatRegulatorOf(receptor)` — one each per receptor, `invalidate(receptor, key)` → promise of the refreshed value, `invalidateByKeyPrefix(receptor, keyPrefix)` → promise of the refreshed values of the held keys under the prefix, `dispose()` — disposes every regulator (and one created after it); every part is an option, the options factory takes the firing policy, the repository factory and the scheduling of the binding and fills the rest (`CNSHomeostatRegulator`, `CNSHomeostatStaleTimeRefetchPolicy`, `hashCNSHomeostatKey`, `Date.now`, merged stimulation contexts) |
| `ICNSHomeostatCorrectionRepository<TKey>` | where records live, by key hash: `peekHomeostatCorrectionState(keyHash)`, `writeHomeostatCorrectionState(keyHash, state)`, `holdHomeostatCorrectionState(keyHash)` / `unholdHomeostatCorrectionState(keyHash)` — the first query of an environment took the key / the last one left it; how long a record stays after that is the repository's choice |
| `ICNSHomeostatFiringPolicy` / `CNSHomeostatFiringPolicy({ isOnline?, isVisible? })` | when a query may fire (`isFiringAllowed`) and fire again for stale or failed data (`isRefiringAllowed`) |
| `ICNSHomeostatRefetchPolicy` / `CNSHomeostatStaleTimeRefetchPolicy({ staleTimeMs, homeostatRefractoryPolicy? })` | when a record goes stale; `homeostatRefractoryPolicy` is `{ initialDelayMs, multiplier, maxDelayMs, jitter? }` — `jitter` (0 to 1, 0 by default) shortens each refractory delay by up to that share, the same share for the same failure |
| `TCNSHomeostasisState<TKey>` | a query's value `{ key, status, firingNumber, error, homeostatRunningFiring }`; `status`: `Idle`, `Firing`, `Paused`, `Restored`, `Failed` |
| `ICNSHomeostatRunningFiring<TKey>` / `CNSHomeostatRunningFiring` | the running request of a key, on every `Firing` value: `firingNumber`, `waitUntilSettled()` — the settled value once the answer's stimulation completed; rejects on abort and on a failed stimulation |
| `createCNSRunQueue(scheduleRunQueued)` | one queue of runs drained in one scheduled call with `cnsRunAll`; both bindings build their after-derivation queue on it |
| `cnsRunAll(runs)` | runs every function; the first error is thrown after the last run, every later one is thrown on its own in a microtask, so none is lost |
| `CNSHomeostatReceptorFetch` / `TCNSHomeostatReceptorRequest` | a helper for `transduce` over `fetch`: `send({ url, method?, body?, headers? }, abortSignal)` → the parsed JSON as `unknown`, `undefined` for a response without a body (204); `timeoutMs?` (30000, `Infinity` for none) rejects a request that has not answered with `METHOD url: timed out after timeoutMs ms` |
| `CNSHomeostatBatchTransducer` / `TCNSHomeostatBatchTransducerOptions` | one request for many keys: `transduceOf(name, parse)` → a `transduce` that joins every key asked until the next macrotask into one `batchTransduceFn(requests, abortSignal)`; the answer is a flat list of rows, a key gets the `data` of its rows as a list; a row with `error` fails its key; the batch is aborted when every key in it is; `batchScheduleFn` replaces the window |
| `TCNSHomeostatTransductionRequest`, `TCNSHomeostatTransductionRow` | the wire: request `{ name, key }`, row `{ name, key, data }`, `{ name, key, error }` or `{ name, key }` (answered, no entity); a key with no row at all fails «was not answered» |
| `ICNSHomeostatTransductionCodec` / `CNSHomeostatTransductionQueryCodec` / `TCNSHomeostatTransductionQueryCodecOptions` / `TCNSHomeostatTransductionCover` | the format of one endpoint: `mediaType`, `dropCoveredRequests?` (what goes in the query), `encodeRequests` / `decodeRequests` (the query), `encodeRows` / `decodeRows` (the answer); the default writes `deck=d1;d2&deckCards=d1` sorted and without repeats, parts by `,`, keys by `;`, `~20` a number, `~` undefined, `~n` null, `~t`/`~f` booleans, `~e` an empty string, and answers a flat list of `[request, data]` / `[request, null, error]` / `[request]` (answered, no entity); `homeostatTransductionCovers: [{ coveringName, coveredName, selectCoveredKey, revision? }]` leaves a covered key out of the query when its covering key is in the batch (also through a chain; a cycle is refused), and the endpoint with the same codec reads it back; the covers are in `mediaType`, so other covers get `406` |
| `CNSHomeostatTransductionFetch` / `TCNSHomeostatTransductionFetchOptions` | the client transport: `{ url, homeostatTransductionCodec?, fetch?, headers?, maxUrlLength?, timeoutMs? }`, `batchTransduceFn` sends one `GET` with the codec's `mediaType` as `Accept`, split into several (the same split for the same keys) when the URL is longer than `maxUrlLength` (4096); a failing `GET` fails only its keys (error with `status`), and so does a `GET` with no answer within `timeoutMs` (30000, `Infinity` for none), a key the codec cannot write fails alone; `url` takes no query or fragment |
| `CNSHomeostatTransductionEndpoint` / `TCNSHomeostatTransductionEndpointOptions` / `TCNSHomeostatTransductionResponse` | the backend: `{ batchTransduceFn, homeostatTransductionCodecs?, maxBatchSize? }`, `respond(query, accept)` picks the codec by `Accept` per RFC 9110 (most specific range sets a codec's `q`, highest `q` wins, `q=0` refuses, ties by codec order, no header → the first; `406` when none fits, `400` for an unreadable query, `413` over `maxBatchSize`) and returns `{ status, headers, body }` with `vary: accept` |
| `CNSHomeostatFiringContext` | what the regulator puts in the stimulation context of a request's signals; the correction neuron writes only for an instance of it |
| `TCNSHomeostatCNS` | what the regulator needs of a CNS: `stimulate(signal, options)`; any `CNS` fits |
| `TCNSHomeostatOutcome`, `TCNSHomeostatOutcomeStatus` | what the correction neuron reduces into a record: an answer of a request, `Restored` or `Failed` |
| `TCNSHomeostatCorrectionState`, `ECNSHomeostatCorrectionStatus`, `TCNSHomeostatRefractoryPolicy`, `computeCNSHomeostatRefractoryDelayMs` | the record of a key (with `invalidationNumber`: the data of a request started before the last invalidate is not delivered and its record stays stale; its failure is written as stale), its status, the backoff after a failure |

The same scenarios — every use case and every part replaced — run on each binding: `src/tests/conformance/cnsHomeostatConformance.ts`.
